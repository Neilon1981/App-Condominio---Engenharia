# 📱 App de Gestão e Comunicação Condominial

Aplicativo multiplataforma para facilitar a administração de condomínios, integrando gestão eficiente, comunicação transparente e segurança.

---

## 🎯 Missão
Facilitar a convivência e a administração em condomínios por meio de uma plataforma digital intuitiva.

## 👀 Visão
Ser o aplicativo de referência em inovação e usabilidade para gestão condominial, transformando a forma como comunidades residenciais interagem.

## 💡 Valores
- Transparência  
- Segurança (adequação à LGPD)  
- Praticidade (usabilidade para todas as idades)  
- Inovação  
- Colaboração  

---

## 📌 Funcionalidades Principais
- Cadastro e gerenciamento de moradores e síndicos (CRUD)  
- Login com níveis de acesso diferenciados (Morador x Síndico)  
- Reservas de áreas comuns com validação de inadimplência  
- Abertura e acompanhamento de ocorrências  
- Envio de comunicados e boletos com notificações push  

---

## ⚙️ Requisitos Técnicos
### Requisitos Funcionais
- RF01: CRUD de moradores e síndicos  
- RF02: Login com autenticação segura  
- RF03: Reservas de áreas comuns  
- RF04: Abertura e atualização de ocorrências  
- RF05: Notificações push de comunicados e boletos  

### Requisitos Não Funcionais
- RNF01: Responsivo e multiplataforma (Android/iOS)  
- RNF02: Criptografia de dados (LGPD)  
- RNF03: Interface acessível para idosos  

---

## 🛠️ Tecnologias
- **Frontend:** React Native ou Flutter  
- **Backend:** APIs REST + Banco de Dados relacional  
- **Infraestrutura:** Serviços em nuvem (Firebase/AWS Educacional - free tier)  

---

## 📲 Protótipos de Telas
- Tela de Login com campos amplos e acessíveis  
- Dashboard do Síndico com gráficos e atalhos rápidos  
- Calendário de Reservas com datas ocupadas e disponíveis  
- Chat interno para acompanhamento de ocorrências
