## 🗂️ EAP – Estrutura Analítica do Projeto

A Estrutura Analítica do Projeto (EAP) organiza as principais fases e entregáveis do desenvolvimento:

1. **Análise e Design**  
   - Definição de Tema/Problema  
   - Levantamento de Requisitos  
   - BPMN  
   - UML  
   - Mockups de Telas  

2. **Backend e Banco de Dados**  
   - Modelagem do banco  
   - Criação de APIs  
   - Desenvolvimento das operações CRUD  

3. **Frontend e Integração**  
   - Desenvolvimento das telas mobile  
   - Integração com as APIs  
   - Validação de portabilidade  

4. **Testes e Implantação**  
   - Testes de usabilidade  
   - Correções do protótipo (MVP)  
   - Liberação da versão Beta  

5. **Encerramento**  
   - Redação da relatoria do projeto  
   - Apresentação para a banca
