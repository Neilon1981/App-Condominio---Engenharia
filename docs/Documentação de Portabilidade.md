## 📱 Documentação de Portabilidade

O aplicativo será desenvolvido utilizando um **framework híbrido** (como React Native ou Flutter), garantindo que o mesmo código fonte seja compilado de forma nativa para os sistemas operacionais **Android** e **iOS**.  
O design será responsivo, adaptando-se a diferentes tamanhos de tela (smartphones e tablets).

Considerando que o TG em si utiliza *tempo dos autores, infraestrutura de desenvolvimento e recursos econômico-financeiros*:

- **Esforço da equipe:**  
  X horas de levantamento de requisitos + Y horas de codificação (Frontend/Backend) + Z horas de testes
